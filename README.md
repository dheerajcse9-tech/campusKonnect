# CampusKonnect

> A trusted digital ecosystem where students exchange resources, opportunities and knowledge.
> **Private · Verified · Trusted**

CampusKonnect is a private, campus-only platform where verified students can **buy, sell and rent** items, **ask seniors** for guidance, and **share knowledge**, with approval-gated contact and admin moderation built in.

## Status

Under active development. The MVP is being built module by module. See the [design docs](docs/README.md).

## Repository layout

```
docs/      Requirements, architecture, database and API design, ADRs
server/    Node.js + Express + TypeScript API (Prisma / PostgreSQL)
client/    React + TypeScript + Tailwind web app
```
